길콕 시제품 개인정보 처리 안내

이 안내는 개발용 시제품의 실제 데이터 흐름을 설명합니다.

1. 차량 및 위치 기록
사용자가 주행 기록을 시작하면 속도, 브레이크, 누적 주행거리, 제공되는 효율 정보, 현재 위치와 시각을 기기 내부에 저장합니다. 기본 내비 화면으로 이동해도 알림이 표시되는 동안 수집이 이어집니다. 알림이나 앱에서 기록을 종료할 수 있습니다.

2. 보관과 삭제
완료한 최근 20건을 보관하며 전체 완료 샘플은 120,000개로 제한합니다. 한 번의 기록은 최대 6시간입니다. 리포트의 '완료한 주행 기록 삭제'에서 삭제할 수 있습니다. 중단된 기록은 별도로 유지되며 종료해서 저장한 후 삭제할 수 있습니다. 앱 데이터 삭제 또는 앱 제거 시 내부 기록·선택한 장소·지도 캐시가 삭제됩니다. 앱 백업은 비활성화했습니다.

3. 선택적인 외부 지도와 검색
외부 지도 이용에 동의하면 지도 화면 영역에 해당하는 타일 요청과 IP 주소가 OpenStreetMap 타일 서버로 전달됩니다. 현재 위치를 지도에 표시하면 요청 영역을 통해 대략적인 위치가 전달될 수 있습니다. 검색 버튼을 누른 경우 검색어를 Nominatim 서버로 보냅니다. 검색 요청에는 현재 좌표를 첨부하지 않습니다. 공개 장소 이름으로 검색하시고 개인 주소 등 비공개 정보를 입력하지 마세요.

지도 이용 동의를 철회하면 지도와 검색 요청을 중지합니다. 외부 서버의 보관 정책은 해당 운영자의 정책에 따릅니다.
https://osmfoundation.org/wiki/Privacy_Policy
https://osmfoundation.org/wiki/Terms_of_Use

4. 주행 기록 전송
길콕은 주행 기록을 자체 분석 서버로 업로드하지 않습니다. 경로 요청 시 선택한 목적지와 경유점은 차량의 Pleos 기본 내비에 전달됩니다. Pleos 내비 서비스의 별도 처리에는 해당 서비스 정책이 적용됩니다.

5. 시제품 배포 전 확인
운영자명·문의처, 실제 배포 지도 서비스 계약과 개인정보 처리 문서는 배포 주체에 맞게 확정해야 합니다. 이 안내는 법률 검토를 완료한 배포용 약관이 아닙니다.
