# 길콕 (Gilkok)

<img src="docs/app_icon.webp" width="96" alt="길콕 아이콘">

> **내가 아는 길을 지도에서 콕 찍으면, 그 길로 가는 경로를 내비 추천 경로와 바로 비교해 주는 Pleos Connect 앱**

2026 현대자동차그룹 차량용 앱 개발 공모전 출품작 · 팀 **샛길연구소** · Pleos Connect (Android Automotive)

**APK 위치:** [`apk/샛길연구소_길콕_release.apk`](apk/)

## 무엇을 해결하나

익숙한 동네에서 내비가 추천한 길보다 **내가 아는 길**로 가고 싶을 때가 많습니다. 기존 내비의 경유지는 "들르는 장소" 기준이라
"이 도로를 지나서 가고 싶다"를 표현하기 어렵고, 두 경로를 나란히 비교하기도 어렵습니다.
길콕은 **지나가고 싶은 길 자체를 탭 한 번으로 지정**하고, 추천 경로와 비교해 고른 뒤, 차량 기본 내비로 그대로 안내받게 합니다.

## 핵심 기능

| 기능 | 설명 |
|---|---|
| **길 콕 찍기** (메인) | 목적지를 고르면 추천 경로가 바로 표시되고, 지도에서 지나고 싶은 길을 탭하면 그 길을 지나는 **길콕 경로**가 함께 그려집니다 (최대 2곳). |
| **경로 비교** | 추천 경로(회청색)와 길콕 경로(청록색)를 한 지도에 겹쳐 보여주고, 시간·거리·예상 연료(L, 도심/고속 비율)를 카드로 비교합니다. 경로가 찍은 길을 실제로 지나는지 검증해 표시합니다. |
| **실시간 교통 반영** (서울) | 서울시 TOPIS 실시간 도로소통정보로 경로가 지나는 구간의 현재 속도를 받아 시간·연료를 다시 계산하고, 정체 구간 비율을 표시합니다. 서울 밖은 기존 계산을 사용합니다. |
| **기본 내비로 안내** | 고른 경로의 콕 지점을 경유지로 Pleos 기본 내비에 넘겨 안내받습니다. |
| **경로 주변 명소** | 한국관광공사 TourAPI로 경로 주변 명소(볼거리·자연·먹거리·행사) 상위 5곳을 지도에 번호로 표시하고, 경로에서의 거리·추가 시간·소개를 보고 경유지로 추가할 수 있습니다. |
| **연비 계산** | 그랜저 하이브리드 공인 도심/고속 연비로 경로별 연료량을 계산합니다 (계산 기준: `docs/FUEL_MODEL.md`). |
| **(개발 중) 운전 습관 피드백** | 주행 기록으로 가속·감속 습관을 피드백하는 기능을 2차 심사 전까지 개발합니다. |

## Pleos SDK 활용

| SDK | 사용 내용 |
|---|---|
| **NaviHelper 3.0.5** | 목적지·경유지(최대 2개) 경로 요청, 현재 위치·목적지 조회, 경로 탐색 이벤트 |
| **Vehicle SDK 2.3.2** | 전비·연비(현재·누적), 누적 주행거리, 브레이크, 주행 모드 |
| **Android Automotive 표준 API** | 차량 속도(`PERF_VEHICLE_SPEED`), 주행 중 조작 제한(`CarUxRestrictions`) |

주행 중에는 입력과 지도 조작이 잠기며, 실제 길 안내는 차량 기본 내비가 맡습니다.

## 실행 방법

> 개발 경험이 없어도 따라 할 수 있게 적었습니다. **Pleos Connect 에뮬레이터가 설치된 PC**가 필요합니다.

### 방법 A. APK로 설치하기 (가장 쉬움, 심사용)

1. **APK 파일 받기**
   - 이 페이지 위쪽 파일 목록에서 **`apk` 폴더** → **`샛길연구소_길콕_release.apk`** 파일을 누릅니다.
   - 오른쪽 위 **다운로드 버튼(⬇, "Download raw file")**을 누르면 PC에 저장됩니다.
2. **에뮬레이터 켜기**
   - Android Studio를 열고 오른쪽 **Device Manager**에서 **Pleos Connect v2.1.0** 옆 **▶**를 누릅니다.
   - 차량 화면(계기판·지도)이 다 뜰 때까지 1~2분 기다립니다.
3. **설치하기**
   - 받은 APK 파일을 **마우스로 끌어서 에뮬레이터 화면 위에 놓습니다.**
   - 잠시 후 설치가 끝납니다(화면에 설치 완료 알림이 뜨거나 아무 반응이 없어도 정상입니다).
4. **실행하기**
   - 에뮬레이터 아래쪽 **앱 목록(⋮⋮ 아이콘)** → **Gilkok**을 누릅니다.
   - 처음 화면에서 **지도 켜기**를 누르고 외부 지도 이용에 동의합니다.

> APK가 아직 `apk` 폴더에 없다면 제출 전 준비 중인 상태입니다. 아래 방법 B로 실행할 수 있습니다.

### 방법 B. 소스 코드로 실행하기 (개발자용)

1. **준비:** Android Studio → `Tools → SDK Manager → SDK Platforms`에서 **Android 37**을 체크하고 설치합니다. (차량 API 파일이 여기 들어 있어서, 없으면 빌드가 실패합니다.)
2. **코드 받기:** 이 페이지의 초록색 **Code** 버튼 → **Download ZIP** → 압축 풀기. (GitHub Desktop을 쓴다면 Clone)
3. **열기:** Android Studio → **File → Open** → 받은 `Gilkok` 폴더 선택 → 아래쪽 진행 막대가 끝날 때까지 기다림 (처음엔 인터넷 연결 필요, 몇 분 걸림)
4. **(선택) 명소 키:** 폴더 맨 위의 `local.properties` 파일 맨 아래에 `TOUR_API_KEY=발급받은_인증키` 한 줄 추가. 없으면 명소는 예시 데이터로 표시됩니다.
   **(선택) 교통 키:** 같은 파일에 `SEOUL_TRAFFIC_KEY=서울열린데이터광장_인증키` 한 줄 추가. 없으면 교통 반영 없이 동작합니다.
   키는 팀 채팅으로만 공유하고 깃허브에 올리지 마세요 (`local.properties`는 업로드 제외됨).
5. **실행:** 에뮬레이터를 켠 뒤 위쪽 초록색 **▶ Run**. (Windows는 `새로고침.bat` 더블클릭으로도 가능)

## 시연 시나리오 (약 2분)

1. **목적지 코엑스** → 추천 경로가 바로 표시됨
2. 지도에서 **평소 아는 길을 탭** → 길콕 경로가 함께 그려지고 시간·거리·에너지 비교
3. **주변 명소 보기** → 지도에 상위 5곳 번호 표시 → 이름을 눌러 사진·소개 확인 → **경로에 추가**
4. **내가 고른 길로 안내 시작** → 차량 기본 내비에 경유지 전달

## 데이터와 정직한 표시

- 경로: OSRM 공개 서버(실제 도로망). 서울 구간은 서울시 실시간 교통으로 시간을 보정하고, 반영된 구간 비율을 화면에 표시합니다. 연결 실패 시 **데모 데이터**로 대체하며 화면에 항상 표시합니다.
- 명소: 한국관광공사 TourAPI. 키가 없거나 실패하면 데모 명소로 대체하고 표시합니다.
- 에너지 값의 근거(내 주행 기록 / 차량 연비·전비 / 기본값)를 항상 함께 표시합니다.
- 주행 기록과 예측값은 **기기 안에만** 저장하며, VIN 등 차량 식별 정보는 수집하지 않습니다.

## 프로젝트 구조

| 파일 | 역할 |
|---|---|
| `KokPoint.kt` | 콕 지점·명소 경유지 모델, 최적 방문 순서 |
| `RouteEngine.kt` | 경로 엔진(OSRM / 데모 / 카카오), 콕 지점 통과 검증, 도로 이름 붙이기 |
| `SeoulTraffic.kt` | 서울시 실시간 교통: 경로 ↔ 도로 링크 매칭, 속도 조회, 시간·정체 재계산 |

| `PoiProvider.kt` | 주변 명소 검색(TourAPI), 추가 시간 순 정렬 |
| `RouteEnergy.kt` | 경로별 예상 에너지, 주행 후 실제값 |
| `NaviClient.kt` | Pleos NaviHelper 연동 |
| `VehicleTelemetry.kt` | Pleos Vehicle SDK + 차량 속도, 주행 중 조작 제한 |
| `TripRecordingService.kt`, `TripStore.kt` | 주행 기록, 기기 내 저장, 습관 분석 |
| `EnergyModel.kt` | 차량 물리 모델 |
| `MapProvider.kt` | MapLibre 지도, 경로·콕 지점·명소 표시 (구글 서비스 불필요) |
| `MainActivity.kt` | 화면 (경로) |
| `assets/seoul_links.bin` | 서울시 도로 링크 좌표 5,265개 (`tools/교통링크_받기.bat` → `tools/make_topis_links.py`로 생성) |
