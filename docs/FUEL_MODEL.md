# 길콕 연비 계산 정리

2026-11-15 · 연비 담당자 공유용

## 1. 목적

추천 경로와 내가 고른 길(길콕 경로)의 **연료 차이**를 보여줍니다. 운전자가 "이 길로 가면 연료가 얼마나 더(덜) 드는지" 보고 판단할 수 있게 하는 것이 목표입니다.

## 2. 기준 차량 (시연용)

**그랜저 하이브리드**, 공인 연비 범위의 **중간값**을 사용합니다.

| 구분 | 공인 범위 | 사용 값 |
| --- | --- | --- |
| 도심 | 15.5 ~ 18.2 km/L | **16.85** |
| 고속 | 16.3 ~ 18.5 km/L | **17.4** |
| 복합 | 15.9 ~ 18.4 km/L | **17.15** (보정 기준) |

## 3. 계산 방법

1. 경로를 **도심 구간과 고속 구간**으로 나눕니다.
   - **고속:** 구간 속도 **70km/h 이상** 도로 (고속도로 + 올림픽대로·강변북로 같은 자동차전용도로)
   - **도심:** 나머지 전부
2. 구간별로 해당 연비로 나눠서 더합니다.

> **연료(L) = 도심 거리(km) ÷ 16.85 + 고속 거리(km) ÷ 17.4**

**예시:** 총 10km = 도심 6km + 고속 4km
→ 6 ÷ 16.85 + 4 ÷ 17.4 = 0.356 + 0.230 = **약 0.59 L**

고속 구간 거리는 경로 서버(OSRM) 응답의 구간별 거리·속도(`annotations=distance,speed`)에서 속도가 70km/h(19.4 m/s) 이상인 구간 거리를 더해 구합니다.

## 4. 화면 표시

- **각 경로 카드:** 연료량(L)과 도심/고속 비율 (예: "연료 1.21 L · 도심 70% · 고속 30%")
- **결론 문장:** 두 경로의 **차이만** (예: "3분 더 걸리고, 연료는 0.05 L 더 필요해요.")
- **근거 표시:** "그랜저 하이브리드 공인 연비 기준 · 예측값 · 교통정보 미반영"

## 5. 나중에 추가할 것 (코드는 준비됨)

| 항목 | 방법 |
| --- | --- |
| **실제 연비 보정** | 차량(Pleos Vehicle SDK)의 실제 누적 연비로 보정. 보정 연료 = 계산 연료 × (공인 복합 ÷ 실제 연비). 예: 실제 14.0이면 17.15 ÷ 14.0 ≈ 1.23배 |
| **차종 선택** | 차종별 공인 도심/고속/복합 연비를 한 줄씩 추가하고 설정에서 선택 |
| **전기차** | 같은 방식에 공인 **도심/고속 전비(km/kWh)** 사용, 단위 kWh |

## 6. 한계 (기획서·발표 때 밝힐 부분)

- **공인 연비 기준:** 실제 연비는 보통 이보다 낮습니다. 실제 연비 보정을 붙이면 줄어드는 한계입니다.
- **교통 정체 미반영:** 막히는 정도는 아직 계산에 들어가지 않습니다.
- **고속 판별은 속도 기준이라 근사치:** 빠른 시내 간선도로가 고속으로 잡힐 수 있습니다.
- **데모 데이터일 때는 고속 비율을 가정:** 추천 경로 25%, 길콕 경로 10%.
